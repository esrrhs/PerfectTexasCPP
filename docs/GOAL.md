# GOAL — 长期自主迭代目标与候选队列

> 本文件是自治循环的「状态机」。看护任务只读本文件 + `docs/ITERATION_LEDGER.md`。
> 每轮结束不征求确认：**出结果 → 写账本 → 判采纳/拒绝 → 更新队列 → 立刻启动下一个 → 再报**。
> 报告是「顺便告诉你」，不是「等你批准」。

## 0. 目标（三层）

- **L0（终极）**：AI 能力追上主流算法。可量化口径 = 对 Slumbot 外部评测、全下 EV 调整后的
  点估计进入采纳线（当前基线 **−0.635 ± 0.289 BB/手，15,000 手**，SE 0.147；12k vs 12k
  差值 2σ ≈ **0.417** → 阈值 **−0.218**），并继续逼近 **0 或更好**。
- **L1（当前阶段）**：修掉**过度弃牌**。验收尺子已固化（R15b）：外部 12,000 手、只算**翻后**
  面对下注的决策，坏弃 = `弃牌 且 eq > 赔率+0.10`，成本 = `eq*(pot+need) − need`。
  基线 **555 次坏弃 / 0.390 BB/手**（其中 `eq−赔率>0.30` 的 392 次占 0.365，即几乎全是
  「胜率远超赔率仍弃」）；继续率 0.5–1× 21.2% vs MDF 0.618、1–1.5× 1.4% vs 0.465。
  要求**坏弃金额 ≥30% 下降（≤0.273 BB/手）**，且 16k H2H 与三锚点不恶化。
  **判据补丁（R27 实测，2026-11-09，取代 R24-rep 时的估计）**：同配方续训 400 update 的
  12k 闸门噪声实测为 **±0.021**（ctrl27001 0.402 / ctrl27002 0.360，极差 0.042）；「尖自对局」
  族 4 臂为 0.325–0.396（均值 0.350，族均值 −8% vs 对照 0.381，不显著）。因此：
  ①任何候选必须在 **≥2 个种子同向**且**≤0.360（对照组最优点）** 才允许上报「下降」；
  ②≤0.273 才算过 L1 采纳线；③单臂单种子的一切读数只当噪声。
  量法：`python3 tools/badfold_diag.py --hands 12000 <facing csv...>`。
- **L2（本轮）**：训练侧四条低成本路子已全部拒绝：R12（奖励 0.10，−5.5%）、**R12b（奖励 0.5，
  +3.5%，弃牌率全面上升）**、R13（大注诈唬对手，+5.3% 且 random 锚点塌）、R17（CE 监督塌缩 /
  引导探索 +2% 且坏跟 +52%）。R17c 给出的机制结论：**`eq·(pot+need) − need` 是「跟注后打得
  完美」的上界，不是可回收 EV**；单独压坏弃会把钱搬到后续街错误，所以必须同时有「跟注后的
  后续街打法」信息。**R18 双向监督也拒绝**（闸门 0.526/+7%、坏跟 0.127=4.1×：完美权益标签
  教出的跟注迁到 Slumbot 状态就是坏跟）。**R21（`--range-eq 16` 同口径）0.481/−2.2%、
  R23（`--oracle-coef 0.10`）0.476/−3.3%，两臂锚点都不降，但坏跟分别 0.025 / 0.082（R23 为
  基线的 2.6×）**——横向证据说明：**坏弃与坏跟在当前策略上是耦合的**，任何「单向放松弃牌」
  都会让坏跟按 1.5–2.6× 放大；问题不是模型崩坏，而是「跟注这个边际决策缺信息」。
  **R24 尖自对局线已收口**：族均值 0.350 vs 对照 0.381（−8%，不显著），R24 的 −18% 是族内低尾；
  **R28–R31 权重汤线也已收口**：汤的闸门读数 = 原臂读数的线性插值（预测/实测偏差 <0.012），
  不是新杠杆。**R32 已修好闸门口径并正式判死 R21/R25**：特征开/关只差 0.002–0.004，
  `rangeEq` 标量通道对策略**没有实际作用**（即使训练时就同口径喂它）。
  **R34 给出了这条线的闭合实证（2026-11-09）**：`--opp-model-coef 0.10` 把坏弃压到 0.354
  （−11.1%，低于对照组最优点），但 **H2H vs stn2 = −100.6 ± 18.7 筹码/手（5σ）**、
  R33 钱口径 +0.232（比基线 +0.268 更差）、坏跟 +17%。即**坏弃下降 = 整体打得更弱**。
  **停点（需用户裁决，属「改评测口径/改方向」）**：L1 的「坏弃金额显著下降」与「H2H 不变差」
  在现有信息架构下**已被证明不能同时成立**（R18 反向实证：坏弃上升、坏跟 4.1×）。
  本目标继续按原 L1 记录指标，但**不再把坏弃当采纳线**；建议改用「翻后反事实 EV（R33 口径）
  + H2H + 外部」三件套。用户裁决前，队列照跑（R22 从零重训进行中）。
- **L3（2026-11-10 22:55 新增，代理口径全线判死）**：R58 证明**「事后损失」离线口径与强度反向**
  （ρ=+0.382；口径最好的 4 个臂 H2H 全负、均值 −68.0 筹码/手），机制是 `loss/pFC` 归一 +
  `best` 只取 fold/call 上界而**从不检验 raise 是否更差** + 计入集合由策略自定
  （`src/main.cpp:3758–3786`）；`tools/fastloop.sh` 头注早在 2026-11-08 就判过它无效。
  R59 又实测 **r24_sharp 内部 −55.1 ± 22.9（−2.4σ）**——正是 R56 押注的基座。
  加上 README 第二节「内部锚点/H2H 与外部排序长期脱钩」，**本地已无任何被验证的便宜代理**：
  每个候选都必须花 ~10.4h 串行外部机时（3.1 秒/手，并发会触发限流）才知道好坏，
  本地迭代率上限 **~2.3 臂/天且接近掷硬币**。这是「追上 Slumbot」的真实瓶颈（R60 已量化）。
- **待用户裁决（GOAL §1 第 1 类停点，两项，2026-11-10 提出）**：
  ① **R62 改评测口径**：放弃「固定 12k」约定、把 R43（−0.2495，1.91σ）与基线**两侧各扩到 ~29k 手**
  （≈27.6h 串行机时、0 花费）以拿到 80% 功效的 2σ 裁决；
  ② **R63 花钱**：云 GPU 走路线 A（AlphaHoldem 式纯 RL，576 GPU-小时、**~$130–1,600**、工程 ≥1–2 周），
  见已定稿的 `docs/DEEP_CFR_FEASIBILITY.md`。两项都不自行启动；R56/R61 照跑。

## 1. 停止条件（只有两种）

1. 需要用户**花钱**或**改方向**的大决策（例如换训练范式、买算力、改评测口径）。
2. L0 达成（外部 12k 点估计 ≥ 采纳线并稳定，或更高）。

其余情况一律「做完即接下一个」，不允许空转、不允许等确认。

## 2. 每轮固定协议

1. 跑完实验，拿到数字（快速环 / 外部 / 离线精度）。
2. 写 `docs/ITERATION_LEDGER.md`：假设、唯一变量、命令、seed、数字、结论。
3. 判采纳/拒绝（按该候选的**成功判据**，不按主观印象）。
4. 更新本文件 §5 候选队列：删掉已做项，补一个新项（**队列不允许为空**）。
5. 立刻启动下一个候选（训练/生成/外部/快速环），更新 §6「当前在跑什么」。
6. 最后再向用户汇报（按轮次，失败照实写）。

## 4. L1 诊断结论（R11，已写账本）

- **不是「不会算赔率」**：actor 的 `x[4]` 就是底池赔率 `need/(pot+need)`（`src/features.cpp`），
  MDF 可由它推出。
- **是「尺寸条件化的范围恐惧」**：同一 eq 区间（0.70–1.00）弃牌率 <0.5× 31.2% → 0.5–1× 71.0%
  → 1–1.5× 93.5% → 1.5–3× 100%。
- **强牌也弃**：翻后 0.5–1.5×，eq≥0.70 弃 117 个（−172,333），eq≥0.80 弃 65 个（−133,539）。
- **规则对照**：只看牌力+赔率（eq>赔率就跟）可回收 **+303,087 筹码 = +0.505 BB/手**（开天眼上界）；
  95.5% 的坏弃损失来自 `eq−赔率 > 0.30` 的 268 个弃牌。
- **数据层修复（R11）失败**：maniac 0.05 让策略变成 3-bet 机器，大池更差 → 拒绝。
- **R14 补充（对手确实在诈唬）**：Slumbot 翻后开池下注的空气占比翻 22.5–27.9%、转 20.2–27.1%、
  河 13.9–22.2%，**不随尺寸消失**；我们 0.5–1× 的继续率只有 26.8/12.4/8.3%，远低于 MDF 63/60/59。
  因此经验防守目标≈MDF 是对的，「继续率上升」本身不是坏事，仍以坏弃金额是否下降为判据。
