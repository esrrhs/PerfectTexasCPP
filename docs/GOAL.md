# GOAL — 长期自主迭代目标与候选队列

> 本文件是自治循环的「状态机」。看护任务只读本文件 + `docs/ITERATION_LEDGER.md`。
> 每轮结束不征求确认：**出结果 → 写账本 → 判采纳/拒绝 → 更新队列 → 立刻启动下一个 → 再报**。
> 报告是「顺便告诉你」，不是「等你批准」。

## 0. 目标（三层）

- **L0（终极）**：AI 能力追上主流算法。可量化口径 = 对 Slumbot 外部 12,000 手、全下 EV 调整后的
  点估计进入采纳线（当前基线 **−0.681 ± 0.163 BB/手**，12k vs 12k 的 2σ ≈ 0.46 → 阈值 **−0.22**），
  并继续逼近 **0 或更好**。
- **L1（当前阶段）**：修掉**过度弃牌**。R10 的 MDF 表实测：坏弃 **519 次 / −578,778 筹码
  ≈ −0.96 BB/手**（大于整体赤字 −0.68）；要求**坏弃金额显著下降**，且 16k H2H 与三锚点不恶化。
- **L2（本轮）**：`r11_bluff` 已验收并**拒绝**（见 §3）；当前主线 = **R12 奖励层软约束**，
  副线 = R10 合并数据精度收口（已完成，见 §4）。

## 1. 停止条件（只有两种）

1. 需要用户**花钱**或**改方向**的大决策（例如换训练范式、买算力、改评测口径）。
2. L0 达成（外部 12k 点估计 ≥ 采纳线并稳定，或更高）。

其余情况一律「做完即接下一个」，不允许空转、不允许等确认。

## 2. 每轮固定协议

1. 跑完实验，拿到数字（快速环 / 外部 / 离线精度）。
2. 写 `docs/ITERATION_LEDGER.md`：假设、唯一变量、命令、seed、数字、结论。
3. 判采纳/拒绝（按该候选的**成功判据**，不按主观印象）。
4. 更新本文件 §5 候选队列：删掉已做项，补一个新项（**队列不允许为空**）。
5. 立刻启动下一个候选（训练/生成/外部/快速环），更新 §6「当前在跑什么」。
6. 最后再向用户汇报（按轮次，失败照实写）。

## 4. L1 诊断结论（R11，已写账本）

- **不是「不会算赔率」**：actor 的 `x[4]` 就是底池赔率 `need/(pot+need)`（`src/features.cpp`），
  MDF 可由它推出。
- **是「尺寸条件化的范围恐惧」**：同一 eq 区间（0.70–1.00）弃牌率 <0.5× 31.2% → 0.5–1× 71.0%
  → 1–1.5× 93.5% → 1.5–3× 100%。
- **强牌也弃**：翻后 0.5–1.5×，eq≥0.70 弃 117 个（−172,333），eq≥0.80 弃 65 个（−133,539）。
- **规则对照**：只看牌力+赔率（eq>赔率就跟）可回收 **+303,087 筹码 = +0.505 BB/手**（开天眼上界）；
  95.5% 的坏弃损失来自 `eq−赔率 > 0.30` 的 268 个弃牌。
- **数据层修复（R11）失败**：maniac 0.05 让策略变成 3-bet 机器，大池更差 → 拒绝。
