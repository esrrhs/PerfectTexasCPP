# 迭代账本（ITERATION LEDGER）

> 长期自治迭代的唯一记账处。每轮**只改一个变量**，走完闭环再进下一轮。
> 只记事实：假设、改动、快速环数字、外部数字、结论、可复现命令。失败直接写失败。

## 0. 目标与判据

- **主指标**：对 Slumbot 外部评测的 BB/手（全下 EV 调整）。
- **当前基线**：`stn2 + T=0.5`，**−0.808 ± 0.229 BB/手（6,088 手，95% CI ±0.449）**。
- **采纳门**：外部 12k 手、点估计 **≥ 基线 + 2σ**（按差值口径约 **+0.60 BB/手**）。
- **最终目标**：基线推到 **0 以上并稳定**；过门只是中途站。
- **诊断指标**（不改判据，只用来定位）：大池（>40BB）EV、SB/BB 分位、河牌弃牌错误成本、动作分布。
- **分辨率上限**：12k 手的候选 SE ≈ 0.17–0.19，2σ ≈ 0.34–0.40；叠加基线 SE 后约 0.60。
  小于这个量级的改进 12k 裁决不了，只能记“不可分辨”，要 36k 以上。

## 1. 每轮闭环

1. **假设**：为什么改这个杠杆、预期哪个指标动、动多少。
2. **快速环**：22 秒烟雾环 + 本地面板（rule/random/solid/mix 等锚点）；崩坏直接否决，不占外部机时。
3. **外部预筛**：过快速环后先打 1500–3000 手，只有明确超过 0.5 BB/手量级才上 12k 终审。
4. **记账**：无论接受/拒绝，都写在本文件。
5. **合并/回滚**：接受 → 更新基线数字与 README；拒绝 → 回滚代码，记录原因。
6. **换杠杆**：同一杠杆连续 3 轮无改善，换到特征表达 / 奖励设计 / 对手池 / 搜索与重解 / 数据规模。

**硬约束**：外部通道同时只跑一条；训练/实验用 `nice` 或限核；每轮留 seed、commit、命令行；
不许改评测口径、挑样本、按对手过拟合温度。

## 2. 轮次记录

### R1 — 2026-11-08 — 判据纠偏（口径轮，非算法轮）

- **假设**：把 `ε ≤ 2 BB/手` 当采纳门是错的——ε 是对最坏对手的保证，和固定对手胜率不是同一个量，
  且 robopoker 从未公开 ε。继续用它会把“表小 + 访问密度高”的路误杀。
- **改动**：
  - ε 降级为诊断项（只记录 ε vs 每 infoset 访问数的斜率）；
  - 采纳统一为外部 12k ≥ 基线 + 2σ；
  - `blueprint-train` 日志新增 `访问/角`；`blueprint-br` 打印访问密度并去掉 PASS/FAIL；
  - 基线更正：旧的 −0.21 ± 0.25 / 5,927 手不可复现，作废。
- **快速环**：`blueprint-br` 在 500K 冒烟表上正常输出；训练日志列格式验证通过。
- **外部**：无（口径轮）。
- **结论**：**接受（口径）**。基线定为 −0.876 ± 0.259 / 4,588 手。
- **commit**：`9db8abd`
- **可复现**：`docs/CFR_BLUEPRINT_PLAN.md` §9.1/§10.6；`docs/ROBOPOKER_CFR_NOTES.md` §5。

### R2 — 2026-11-08 — 瘦 key 对照（已完结，**拒绝**）

- **假设**：如果 ε 主要受“每 infoset 访问密度”支配，那么把底池桶与跨街历史移出 key 后，
  同样迭代数下 ε 应明显低于 `b256_r0`（260K 角、30M 时 ε=25.70）。
- **改动**：`packInfoset` 新增 `--key-slim`（slim=1 时 `potBucket(32)` 与 `hist(8bit)` 置零，
  key 只剩 `street + 牌桶 + 当前街序列 + 1 bit 座位`）；`meta.txt` 持久化 `slim`，
  train/br/distill/eval 自动跟随，混用拒跑。
- **快速环**：500K 冒烟 → 39,615 角、30k iter/s、无崩坏。
- **BR 结果**（1000 抽样、seed 424242、同抽象内抽样 BR）：

| 表 | 迭代 | 角数 | 访问/角 | ε（BB/手） |
|---|---:|---:|---:|---:|
| **slim B=256** | 30M | 40,194 | 746 | **47.818 ± 1.180** |
| **slim B=256** | 60M | 40,209 | 1,492 | **45.408 ± 1.091** |
| 对照 b256_r0 | 30M | 260,560 | 115 | 25.702 |
| 对照 b256_r1 | 60M | 1,387,344 | 43 | 22.691 |

- **结论**：**拒绝**。瘦 key 没有降低 ε，反而约为对照的 1.8–1.9 倍；60M 相对 30M 只降 5%
  （与 M0 的慢斜率一致）。**访问密度不是约束，key 里的信息量才是**——底池桶与跨街历史
  不是“表胖”，而是承载了 SPR/跨街范围信息。移走它们又不像 robopoker 那样补子博弈重解，
  只会让抽象更粗、更易被剥削。一句话归因：**我们缺的是翻后重解，不是 key 太胖。**
- **后果**：按预设裁决，**表格 CFR 路线关闭**（不是“暂停待裁”）；不再做 R3（argmax/重解混合），
  表格 CFR 不再占用迭代预算。
- **commit**：`9db8abd`
- **可复现**：
  `./build_rl/perfecttexas blueprint-train --iters 60000000 --save-every 10000000 --out ~/models/r2/b256_slim --buckets 256 --key-slim 1 --seed 777`
  `./build_rl/perfecttexas blueprint-br --bp ~/models/r2/b256_slim --buckets 256 --key-slim 1 --samples 1000 --seed 424242 --by-street`

### R3 — 2026-11-08 — 联赛配比（对手池）：ctrl vs man

- **假设**：外部亏损高度集中在大池（s96004/s96005 的 >40BB 手分别贡献 −245k / −107k，
  其余手合计约 +0.1~0.3 BB/手）。现役联赛里没有专门惩罚“过度下注 / 小注骚扰”的对手，
  把自对局配额换成这两类剥削型对手，应改善大池 EV，而对规则/稳健锚点不崩。
- **改动**（唯一变量 = 联赛配比，其余超参完全相同，均从 `stn2` 续训 1500 update × 512 局）：

| 臂 | 自对局 | 小注骚扰 | 过度下注 | 其余 |
|---|---:|---:|---:|---|
| `abl_ctrl` | 0.05 | 0.00 | 0.00 | 历史 0.15(archive .30) / 规则 .08 / 随机 .05 / 稳健 .35 / 紧全下 .05 / 陷阱 .05 / 强价值 .15 / 按尺寸弃牌 .07 |
| `abl_man` | 0.00 | 0.04 | 0.08 | 同上 |

  设计缺陷（如实记录）：两臂权重和 1.00 vs 1.07，采样归一化后 man 臂其余类各缩水约 6.5%，
  不是严格的质量匹配；结论只在“整组配比”层面成立，不能拆成单类归因。
- **快速环**（16k 手 H2H vs `stn2`，seed 424242，range-search 0）：

| 臂 | H2H 筹码/手 | >4000 底池 | 其余 | solid | rule |
|---|---:|---:|---:|---:|---:|
| `abl_ctrl` | **+13.0 ± 20.5** | 1762 手 **+227.5** | 14238 手 −13.5 | +503.3 ± 58.5 | +1933.7 ± 112.0 |
| `abl_man` | **−24.1 ± 25.5** | 3398 手 **−179.7** | 12602 手 +17.8 | +627.4 ± 60.4 | +2008.0 ± 123.6 |

  两臂锚点均未崩坏。`abl_man` 把大池手数推到近两倍（3398 vs 1762）且大池 EV 为负，
  机制上是“更激进、更多大池、但大池打得差”；`abl_ctrl` 恰好在大池上 +227.5，
  与假设方向一致，但 H2H 总差 +13.0 落在噪声内（SE 20.5）。
- **外部预筛**：`abl_ctrl` 1500 手（seed 96006）进行中，`abl_man` 排队串行。
- **判据**：1500 手 SE ≈ 0.47，与基线（SE 0.229）比较的差值 SE ≈ 0.52；
  只有点估计 **≥ −0.808 + 0.5** 才继续上 12k，否则记“不可分辨”并换杠杆。
- **可复现**（ctrl 臂；man 臂把 `--spammer-prob 0 --maniac-prob 0` 换成 `0.04 / 0.08`）：

  自对局概率是残差（`1 − 其余概率和`），没有独立开关；完整配比以训练日志首行的
  `league:` 行为准（`~/models/abl_ctrl.log`、`~/models/abl_man.log`）。
